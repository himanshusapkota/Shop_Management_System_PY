# Shop Management System (Python)

A simple terminal-based Shop Management System built with Python. :)

This project allows you to manage products, record sales, track stock, calculate profits, and export records into CSV files — all directly from your terminal.

## Features

- **Product Management:** Add, view, search, update, and delete products.
- **Sales Management:** Sell products, automatically update stock, and calculate total sales and gross profit.
- **CSV Data Storage:** Automatically saves product and sales records in CSV files.
- **Low Stock Alerts:** Get notified when a product's stock falls below 5 units.
- **Sales Reports:** View sales records and track your shop's performance.
- **Data Export:** Export records into CSV files for easy access and management.

## How to Run

You need Python installed on your system.

**1. Clone this repository**

```bash
git clone https://github.com/himanshusapkota/Shop_Management_System_PY.git
```

**2. Navigate to the project directory**

```bash
cd Shop_Management_System_PY
```

**3. Run the program**

```bash
python main.py
```

## Build an EXE (Windows)

You can also convert the Python program into a standalone Windows executable.

**1. Install PyInstaller**

```bash
pip install pyinstaller
```

**2. Build the executable**

```bash
pyinstaller --onefile main.py
```

**3. Run your executable**

Your `.exe` file will be available inside the `dist` folder.
